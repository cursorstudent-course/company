# Задача · Памятка новому руководителю

Вас переводят. Преемнику нельзя сказать «почитай всю папку».
Соберите **одну страницу** на входе.

## Файлы (@) — только эти

1. Этот файл  
2. `06-Совещания/протоколы/2025-03-14_дебиторка.md`  
3. `06-Совещания/протоколы/2025-09-08_дебиторка_снова.md`  
4. `06-Совещания/протоколы/2026-01-22_поручение_дебиторка.md`  

Режим: **Ask** (достаточно) или Agent с целью «только памятка».

---

## Формат

1. Таблица: дата | что решили | кто отвечал | статус по тексту  
2. Три хвоста, которые не закрыты  
3. Кого встретить в первую неделю (роли из файлов, без новых фамилий)  
4. Чего в протоколах нет — и из‑за этого можно наступить на те же грабли  
5. Текст памятки ≤ 1 страницы + «Требует проверки»

Ограничения: не выдумывать статусы; не назначать новых ответственных по имени из головы.
