# Задача · Сверка выручки (без SQL)

## Ситуация

Коммерческий директор называет выручку июня 40,5 млн, финансовый — 39,8 млн.
Перед оперкомитетом нужно показать различие периметров, не выбирать виноватого.

## Файлы (добавить через `@`)

1. Этот файл
2. `03-Отчеты/финансы/версия_2/Отчет_финансы_июнь.md`
3. `03-Отчеты/продажи/версия_3/Отчет_продажи_июнь.md`
4. `04-Таблицы/показатели_по_месяцам.csv`

Второй проход, только если нужно проверить состав продаж: `04-Таблицы/продажи_заказы.csv`.

Режим: **Ask** (для записи файлов — **Agent**, одна цель). Не открывать всю company.

## Что сделать

Напишите:
1. Таблица: показатель | источник А | источник Б | разница | вопрос
2. Возможные причины расхождения — без обвинений
3. Что нельзя утверждать без дополнительной сверки

Нет в файлах → «не указано». Не выдумывайте факты вне приложенных источников.

## Режим А · тренировка РКФО

Не копируйте весь этот файл в чат.  
Напишите **свой** запрос по РКФО и добавьте `@` только из списка выше.

## Готовый запрос (режим Б) · Ask · модель: GPT-5.4 Mini

Шаг 1. Добавьте через @ ровно эти файлы:
  @03-Отчеты/финансы/версия_2/Отчет_финансы_июнь.md
  @03-Отчеты/продажи/версия_3/Отчет_продажи_июнь.md
  @04-Таблицы/показатели_по_месяцам.csv

Шаг 2. Скопируйте текст ниже целиком:

```
Ты — аналитик, который ищет расхождения между отчётами и таблицами. Не выбираешь, кто прав.
Работай только по приложенным файлам. Другие файлы и папки не открывай.

Задача: коммерция называет выручку июня 40,5 млн, финансы — 39,8 млн. Перед
оперкомитетом покажи различие периметров, не выбирая виноватого.

Ответ дай строго в таком порядке:
1. Таблица: показатель | источник А | источник Б | разница | вопрос
2. Возможные причины расхождения — без обвинений
3. Что нельзя утверждать без дополнительной сверки

Правила:
- После каждой цифры и важного факта в скобках укажи имя файла, откуда это взято.
- Если данных нет — напиши «не указано». Ничего не додумывай.
- Не задавай мне встречных вопросов, сразу дай результат.
```

## Если ответ получился слабым

1. Допишите в чат (ещё на **GPT-5.4 Mini**):

```
Перепиши ответ. После каждой цифры и факта в скобках укажи имя файла-источника.
Если данных нет — «не указано». Не задавай встречных вопросов.
```

2. Если снова слабо — **новый чат** · модель **Sonnet 5** или **GPT-5.4** · те же `@` и тот же текст запроса.
