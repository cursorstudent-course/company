# 01 · Записка к оперкомитету

## Ситуация

Оперкомитет 10.07. Нужна короткая служебная записка директору:  
какие цифры июня спорные между коммерцией и финансами, что решать сегодня.  
Не пересказ всех отчётов — управленческий фокус.

## Файлы (добавить через `@`)

1. Этот файл  
2. `03-Отчеты/продажи/версия_3/Отчет_продажи_июнь.md`  
3. `03-Отчеты/финансы/версия_2/Отчет_финансы_июнь.md`  
4. `03-Отчеты/сводка_для_директора/Оперативная_сводка.md`  
5. По желанию (+1): `09-Расхождения/02_маржа_продажи_и_финансы.md`  

Режим: **Ask**. Не открывать всю company.

## Что сделать

1. Главный вопрос на оперкомитет (одно предложение)  
2. Таблица: показатель | коммерция | финансы | сводка ГД | источник  
3. 3–5 расхождений с формулировкой «в чём спор»  
4. 3–5 вопросов участникам (с ролями из файлов)  
5. Что нельзя утверждать без сверки  

Нет в файлах → «не указано». Не выдумывайте NPV, штрафы и новые фамилии.

## Режим А · тренировка РКФО

Не копируйте весь этот файл в чат.  
Напишите **свой** запрос по РКФО и добавьте `@` только из списка выше.

Подсказка букв: **Р** — помощник руководителя · **К** — отчёты через `@` ·  
**Ф** — записка по пунктам выше · **О** — только факты из файлов.

## Готовый запрос (режим Б) · Ask · модель: GPT-5.4 Mini

Шаг 1. Добавьте через @ ровно эти файлы:
  @03-Отчеты/продажи/версия_3/Отчет_продажи_июнь.md
  @03-Отчеты/финансы/версия_2/Отчет_финансы_июнь.md
  @03-Отчеты/сводка_для_директора/Оперативная_сводка.md
  @09-Расхождения/02_маржа_продажи_и_финансы.md

Шаг 2. Скопируйте текст ниже целиком:

```
Ты — помощник руководителя производственной компании ООО «СеверПром». Пишешь коротко, по делу.
Работай только по приложенным файлам. Другие файлы и папки не открывай.

Задача: Оперкомитет 10.07. Нужна короткая служебная записка директору: какие цифры июня спорные между коммерцией и финансами, что решать сегодня. Не пересказ всех отчётов — управленческий фокус.

Ответ дай строго в таком порядке:
1. Главный вопрос на оперкомитет (одно предложение)
2. Таблица: показатель | коммерция | финансы | сводка ГД | источник
3. 3–5 расхождений с формулировкой «в чём спор»
4. 3–5 вопросов участникам (с ролями из файлов)
5. Что нельзя утверждать без сверки

Правила:
- После каждой цифры и важного факта в скобках укажи имя файла, откуда это взято.
- Если данных нет — напиши «не указано». Ничего не додумывай.
- Не задавай мне встречных вопросов, сразу дай результат.
```

## Если ответ получился слабым

1. Допишите в чат (ещё на **GPT-5.4 Mini**):

```
Перепиши ответ. После каждой цифры и факта в скобках укажи имя файла-источника.
Если данных нет — «не указано». Не задавай встречных вопросов.
```

2. Если снова слабо — **новый чат** · модель **Sonnet 5** или **GPT-5.4** · те же `@` и тот же текст запроса.
