# Организационная схема · кратко

```
Генеральный директор
├── Финансы
├── Коммерция (продажи)
├── Производство (1 линия)
├── Логистика и закупки
├── Склад
└── Офис проектов (ERP)
```

**Правило стыков (где чаще всего ломается):**

1. Коммерция обещает срок клиенту → производство не успевает без К-12  
2. Логистика везёт К-12 → финансы режут запас «чтобы не замораживать деньги»  
3. Финансы и коммерция считают **маржу по-разному**  
4. Проект ERP рисует «зелёный» статус → люди на местах считают в Excel
