# Бонусы отдела продаж (2026)

1. Квартальный бонус менеджера = **1,2% от выручки CRM** по закреплённым клиентам (статус «выигран» / отгружено в CRM).
2. Дополнительный KPI руководителя коммерции: выполнение выручки CRM за квартал vs план.
3. Маржа и DSO **не входят** в расчёт бонуса менеджера.
4. Скидки свыше 8% — только с письменного согласования коммерческого директора (регламент с 01.04.2026).
5. Источник цифр для бонуса — **выгрузка CRM**, не управленческий учёт финансов.
