# Администрация района · объявление · 07.07.2026

С **14.07.2026 по 21.07.2026** перекроют участок дороги у промышленной зоны
(подъезд к складу СеверПром и соседним площадкам) — ямочный ремонт.

Фуры длиннее 8 м — только через объезд по ул. Заводская (+12 км, грунтовый
участок после дождя непроезжий).

Логистике: пересчитать окна отгрузки УралСтрой / СибМонтаж на эту неделю.
Складу: не копить отгрузки «на пятницу 17.07» — фура может не проехать.
