# Data quality checks

1. У каждого `customer_id` должен быть ИНН.  
2. `qty_erp` и `qty_physical` по критичным SKU сверяются еженедельно.  
3. Сделки CRM `won` должны иметь отражение в ERP sales_orders.  
4. Документы с `valid_until` < today не используются в board pack без пометки.  
5. Платежи vendor consulting > 500k — проверка договора и акта.
