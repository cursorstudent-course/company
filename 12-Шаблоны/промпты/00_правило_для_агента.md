# Правило для агента · шаблоны Word

Ты заполняешь **документы по бланкам**. Бланки священны.

## Обязательно

1. **Никогда** не изменяй файлы-бланки в корне `12-Шаблоны/*.docx` (кроме создания новой копии).  
2. Сначала создай копию:  
   `12-Шаблоны/_черновики/ГГГГ-ММ-ДД_<тип>_<тема>.docx`  
3. Заполняй **только копию**.  
4. Цифры, даты, ФИО, суммы — только из файлов, которые пользователь дал через `@`.  
   Нет данных → «не указано» / оставь плейсхолдер.  
5. Сохрани разделы бланка. Добавь **«Требует проверки»** в конце.  
6. В ответе укажи: путь к копии + таблица «поле → значение → источник».

## Способы

| Способ | Когда |
|--------|--------|
| A. Копия + правка docx | Умеешь писать docx / есть Viewer |
| B. Замена `{{ПОЛЕ}}` | В бланке плейсхолдеры |
| C. Собрать `.md` по структуре бланка | Viewer капризничает; оригинал docx не трогать |
| D. Текст секциями в чат | Пользователь вставит сам |

## Запреты

- Не пиши в `_заполненные/` поверх чужих примеров без просьбы  
- Не открывай всю company и лишние папки  
- Не выдумывай пени, штрафы ФНС, медицинские диагнозы
