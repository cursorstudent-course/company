# 12 · Шаблоны документов (Word)

Пустые бланки **в формате `.docx`** для практики «черновик документа» (День 3).

Нужен **Office Viewer** (или аналог) в Cursor — иначе Word не откроется нормально.

## Файлы

| Файл | Тип |
|------|-----|
| `Служебная_записка.docx` | внутренняя записка руководителю |
| `Коммерческое_предложение.docx` | КП клиенту / партнёру |
| `Договор_услуги.docx` | типовой договор оказания услуг |
| `Протокол_совещания.docx` | протокол с поручениями |
| `Письмо_претензия.docx` | претензия контрагенту |
| `Отчёт_статус_проекта.docx` | статус проекта на 1 страницу |

## Как использовать в Cursor

1. Выберите шаблон под тип документа  
2. `@` шаблон `.docx` + 2–3 файла с фактами (отчёт, письмо, сводка)  
3. Режим **Ask**: «Заполни шаблон. Цифры только из приложенных файлов.
   Добавь / заполни раздел „Требует проверки“. Структуру шаблона не ломай.»  
4. Не отправляйте результат без проверки чеклистом  

Учебные бланки ООО «СеверПром». Не использовать как реальные документы.
