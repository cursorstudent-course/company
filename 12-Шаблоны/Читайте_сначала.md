# 12 · Шаблоны документов

Пустые бланки для практики «черновик документа» (День 3 курса).

**Как использовать в Cursor:**

1. Выберите шаблон под тип документа  
2. `@` шаблон + 2–3 файла с фактами (отчёт, письмо, сводка)  
3. Режим **Ask**: «Заполни шаблон. Цифры только из приложенных файлов.
   Добавь раздел „Требует проверки“. Структуру шаблона не ломай.»  
4. Не отправляйте результат без проверки чеклистом  

| Файл | Когда брать |
|------|-------------|
| `Служебная_записка.md` | внутренняя записка руководителю |
| `Коммерческое_предложение.md` | КП клиенту / партнёру |
| `Договор_услуги.md` + `.docx` | типовой договор оказания услуг |
| `Протокол_совещания.md` | протокол с поручениями |
| `Письмо_претензия.md` | претензия / требование контрагенту |
| `Отчёт_статус_проекта.md` | статус крупного проекта одной страницей |

`.docx` открывается через расширение **Office Viewer** в Cursor.
Если Viewer нет — используйте `.md`-версию того же шаблона.
