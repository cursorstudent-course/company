# 12 · Шаблоны документов (Word)

Пустые бланки **`.docx`** для практики «черновик документа» (День 3 и дальше).

Нужен **Office Viewer** (или аналог) в Редакторе.

## Правило №1

**Оригинал бланка не изменять.**  
Сначала копия → потом заполнение только копии.

```
12-Шаблоны/
├── *.docx                 ← бланки (священны)
├── _черновики/            ← сюда копировать перед заполнением
├── _заполненные/          ← примеры, не для задания
└── промпты/               ← готовые запросы для агентов
└── структуры/              ← Markdown и карта полей для модели
```

## Бланки

| Файл | Тип |
|------|-----|
| `Служебная_записка.docx` | внутренняя записка |
| `Коммерческое_предложение.docx` | КП |
| `Договор_услуги.docx` | договор услуг |
| `Протокол_совещания.docx` | протокол |
| `Письмо_претензия.docx` | претензия |
| `Отчёт_статус_проекта.docx` | статус проекта |

## Как работать (человек)

1. Прочитайте одноимённый файл в `структуры/` и выберите поля.
2. Скопируйте бланк в `_черновики/ГГГГ-ММ-ДД_тип_тема.docx`.
3. `@` **копию** + 2–3 файла фактов.
4. Ask: подготовить значения полей; Agent: заполнить только копию и добавить «Требует проверки».
5. Оригинал в корне `12-Шаблоны/` не трогать.

## Как работать (агент)

См. [`промпты/00_правило_для_агента.md`](промпты/00_правило_для_агента.md) и промпты 01–06.

Способы: копия+правка DOCX · значения по карте полей · черновик `.md` · текст только в чат.
Список полей и обязательность — в `структуры/поля.json`. Markdown — удобный
вход для модели; DOCX остаётся формой итогового документа.

Для реквизитов всегда используйте `00-О_компании/реквизиты.md`. Если напечатанный
заголовок DOCX расходится с ним, исправляйте копию и добавляйте расхождение в
«Требует проверки».

Учебные бланки ООО «СеверПром». Не использовать как реальные документы.
