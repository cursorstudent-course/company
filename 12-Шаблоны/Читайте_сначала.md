# 12 · Шаблоны документов (Word)

Пустые бланки **`.docx`** для практики «черновик документа» (День 3 и дальше).

Нужен **Office Viewer** (или аналог) в Редакторе.

## Правило №1

**Оригинал бланка не изменять.**  
Сначала копия → потом заполнение только копии.

```
12-Шаблоны/
├── *.docx                 ← бланки (священны)
├── _черновики/            ← сюда копировать перед заполнением
├── _заполненные/          ← примеры, не для задания
└── промпты/               ← готовые запросы для агентов
```

## Бланки

| Файл | Тип |
|------|-----|
| `Служебная_записка.docx` | внутренняя записка |
| `Коммерческое_предложение.docx` | КП |
| `Договор_услуги.docx` | договор услуг |
| `Протокол_совещания.docx` | протокол |
| `Письмо_претензия.docx` | претензия |
| `Отчёт_статус_проекта.docx` | статус проекта |
| `Договор_поставки_ПромТех.docx` | поставка (доп. бланк) |

## Как работать (человек)

1. Скопируйте бланк в `_черновики/ГГГГ-ММ-ДД_тип_тема.docx`  
2. `@` **копию** + 2–3 файла фактов  
3. Ask/Agent: заполнить копию; раздел «Требует проверки»  
4. Оригинал в корне `12-Шаблоны/` не трогать  

## Как работать (агент)

См. [`промпты/00_правило_для_агента.md`](промпты/00_правило_для_агента.md) и промпты 01–06.

Способы: копия+правка docx · замена `{{ПОЛЕ}}` · черновик `.md` · текст только в чат.

Учебные бланки ООО «СеверПром». Не использовать как реальные документы.
