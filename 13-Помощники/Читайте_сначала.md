# 13 · Помощники: папка, правила, роль

Стартовый набор для Дня 4. Здесь **тексты правил**, а не готовые скрытые папки —
чтобы вы собрали конструкцию своими руками и потом повторили дома.

---

## Идея одной фразой

**Чат — это разговор. Папка — это рабочее место.**

Память чата живёт внутри диалога и теряется. Память папки живёт в файлах:
через месяц она на месте, и её может открыть коллега.

| | Чат (DeepSeek и любой другой) | Папка в Редакторе |
|--|-------------------------------|-------------------|
| Где память | в текущем диалоге | в файлах на диске |
| Новый разговор | с нуля | правило подхватывается само |
| Правила поведения | вставляете каждый раз | один раз в `.mdc` |
| Файлы | копипаст текстом | `@` на файл, версия видна |
| Через месяц | ничего не осталось | папка на месте |

---

## Архитектура

```
AI-помощники/
├── 00-Общее/              ← почта, регистрация, контекст обо мне
│   ├── почта/
│   ├── регистрация.md
│   └── контекст-обо-мне.md
├── 01-Ассистент/
│   └── .cursor/rules/ассистент.mdc
├── 03-Экономист/
│   └── .cursor/rules/экономист.mdc
└── …
```

Три правила:

1. **Одна папка — одна роль.**
2. **Правило описывает поведение** (тон, ограничения, куда писать), а не задачу.
3. **В окне — один помощник + `00-Общее`.** Всех агентов в один workspace не открываем.

---

## Два измерения правила

| Измерение | Что задаёт | Где взять |
|-----------|------------|-----------|
| **Поведение** | роль, тон, формат, запреты | `правила/` |
| **Хранение** | куда класть записи и письма в общую почту | [хранение.md](хранение.md) |

Короткие правила из `правила/` — старт. Как выглядят через месяцы: [примеры/](примеры/).

---

## Как собрать одного помощника · 5 минут

1. Создать папку с именем роли, например `01-Ассистент`
2. Положить внутрь 2–4 своих файла + `профиль.md`
3. Внутри папки создать `.cursor/rules/ассистент.mdc`
4. Скопировать текст из `правила/ассистент.md` — **вместе с шапкой** `---`
5. Дописать блок «Хранение» и по желанию «После ответа» (см. хранение.md)
6. Открыть Ask и задать рабочий вопрос
7. Проверить: *«какие у тебя правила по этой папке?»*

Если правило не подхватилось: `.cursor` в корне **этой** папки, файл на `.mdc`.

---

## Workspace: один помощник + общее

1. **File → Open Folder…** — папка помощника  
2. **File → Add Folder to Workspace…** — `00-Общее`  
3. **File → Save Workspace As…** → `экономист.code-workspace`

Сменили роль — открываете **другой** workspace (другая папка роли + то же `00-Общее`).

Пример: `помощники.code-workspace.txt`.

---

## Почта между ролями

В `00-Общее/почта/` помощники оставляют короткие выводы друг другу.
В правило можно прописать: после ответа сам сохрани письмо как
`от-<роль>-<кому>_<тема>.md`.

Регистрация ролей: `00-Общее/регистрация.md`.

## Готовые правила

| Файл | Роль |
|------|------|
| `правила/ассистент.md` | входящие, задачи, «что я забыл» |
| `правила/наставник.md` | инструкции, обучение, объяснить просто |
| `правила/юрист.md` | регламенты, локальные акты, договоры |
| `правила/hr.md` | трудные разговоры, кадровые ситуации |
| `правила/экономист.md` | чужие расчёты, КП, финмодели |
| `правила/планировщик.md` | неделя, приоритеты, делегирование |
| `правила/скептик.md` | проверить собственные выводы |
| `правила/редактор.md` | письма и тексты |
| `правила/переговорщик.md` | подготовка к сложному разговору |
| `правила/дневник.md` | разбор ситуаций, рефлексия недели |

Границы для `дневник`: AI — не врач и не психотерапевт. Медицинские данные,
диагнозы и чужие персональные данные в чат не кладём.
