# Итоги

Сюда роли складывают **выводы**, которыми обмениваются между собой.

Правила гигиены:

1. Один файл — один вывод. Имя говорящее: `расчёт-выводы.md`, `риски-договор.md`
2. В файле: что решили, на каких фактах, что осталось проверить
3. Переписку и черновики сюда не сваливаем — только результат
4. Устарело — удаляем, а не копим

Пример использования: экономист посчитал → сохранили вывод сюда → ассистент
берёт его через `@` и готовит записку руководителю.
