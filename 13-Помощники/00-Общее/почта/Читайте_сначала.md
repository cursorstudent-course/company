# Почта между помощниками

Сюда Agent кладёт короткие выводы после ответа — если так прописано в правиле.

Имя файла:

```
от-<кто>-<кому>_<тема>.md
```

Примеры:

- `от-экономиста-ассистенту_расчёт-линии.md`
- `от-юриста-hr_переработки.md`

Внутри файла:

1. Дата  
2. Краткий вывод (5–10 строк)  
3. На каких файлах основан  
4. Что осталось проверить  

Не сваливаем сюда стенограммы чатов — только то, что должен увидеть другой помощник.
