# Регистрация помощников

Одна строка на роль. Обновляйте, когда добавляете нового.

| Роль | Папка | Workspace-файл | Когда звать |
|------|-------|----------------|-------------|
| Ассистент | `01-Ассистент/` | `ассистент.code-workspace` | входящие, «что я забыл» |
| Экономист | `03-Экономист/` | `экономист.code-workspace` | чужой расчёт, КП, смета |
| Юрист | `04-Юрист/` | `юрист.code-workspace` | договор, регламент, риск |
| | | | |

В одном окне Редактора одновременно открыт **один** помощник + эта папка `00-Общее`.
