Переименуйте этот файл в «помощники.code-workspace» и положите рядом с папками
помощников. Пути правьте под свои имена папок.

{
  "folders": [
    { "path": "00-Общее",    "name": "00 · Общее" },
    { "path": "01-Ассистент", "name": "01 · Ассистент" },
    { "path": "02-Дневник",   "name": "02 · Дневник" },
    { "path": "03-Экономист", "name": "03 · Экономист" },
    { "path": "04-Юрист",     "name": "04 · Юрист" }
  ],
  "settings": {}
}

Проще собрать это мышкой:
File → Add Folder to Workspace… (для каждой папки)
File → Save Workspace As… → помощники.code-workspace
