Переименуйте в «экономист.code-workspace» (или другое имя роли)
и положите рядом с папками. Пути правьте под себя.

Важно: в одном workspace — ОДИН помощник + 00-Общее.
Не добавляйте сюда сразу юриста, HR и остальных.

{
  "folders": [
    { "path": "03-Экономист", "name": "03 · Экономист" },
    { "path": "00-Общее",     "name": "00 · Общее" }
  ],
  "settings": {}
}

Проще мышкой:
1. File → Open Folder… → папка помощника
2. File → Add Folder to Workspace… → 00-Общее
3. File → Save Workspace As… → экономист.code-workspace

Для второй роли — отдельный файл workspace (тот же 00-Общее, другая папка роли).
