# Словарь расходов

Синтетические местные расходы, не счета, выручка или кредитные решения. 900 операций, 1 августа–31 октября 2026. Все суммы в рублях, без валютных пересчётов.

- ID: Стабильный ID операции; ссылки делать по нему и номеру строки.
- Дата: Дата отражения, август–октябрь 2026, Excel date.
- Подразделение: Функция из канона, не выдуманный новый отдел.
- Категория: Расходная категория; пустые включить как «не указано».
- Контрагент: Вымышленный учебный поставщик.
- Описание: Назначение расхода.
- Сумма: Число RUB: расход плюс, возврат минус.
- Валюта: Только RUB.
- Основание: Учебный номер документа.
- Связь: ID исходной операции для возврата; иначе пусто.

Суммировать подписанные суммы по дате отражения, включая возвраты в месяце возврата. Пустая категория не исключает строку из итога. Не вычитать возврат второй раз. Кандидатов в дубли сохранять в итогах до документального решения. Совпадение даты, суммы, подразделения, контрагента, описания и основания — повод проверки, не доказанная ошибка. Отдельная рабочая копия, исходник неизменен. Строка 1 содержит заголовок; EXP-0001 находится в строке 2. Исторические расходы не определяют цены визита.
