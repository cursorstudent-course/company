# СеверПром · начать здесь

Это учебная компания. Все данные вымышлены и не предназначены для реальных
платежей, договоров или кадровых решений.

## Быстрый маршрут

1. Откройте эту папку в редакторе.
2. Возьмите одну карточку из `11-Задачи_для_AI/`.
3. Передайте через `@` только файлы из блока «Файлы» этой карточки.
4. Работайте в Ask; Agent включайте только для создания копии или записи результата.
5. Начните с собственного запроса по РКФО. Если застряли, используйте готовый запрос
   внизу карточки.
6. Проверьте каждый факт по источнику. В Word сначала создайте копию бланка.

участника. Полная карта наборов — в `файлы-по-дням.md`.

## Безопасность

Не передавайте ИИ пароли, токены, реальные персональные данные и рабочую тайну.
ИИ даёт черновик: подпись, платёж, договор, кадровое и юридическое решение остаются
за человеком и ответственным специалистом.
