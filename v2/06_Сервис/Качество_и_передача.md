# Разрыв между продажей и сервисом

По УралСтрой и СибМонтаж сервис не имеет:

- имени следующего менеджера, если Сидоров уйдёт;
- перечня обещаний по сроку отгрузки;
- отметки, можно ли обсуждать с клиентом простой 18.06.

Пока этого нет, сервис может говорить только о своей заявке и только о факте срока реакции.
Причину, по которой менеджер думает об уходе, клиенту не сообщать. Её в сервисных файлах и нет.
