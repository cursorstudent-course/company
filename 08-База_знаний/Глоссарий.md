# Глоссарий СеверПром

| Термин | Значение |
|--------|----------|
| **К-12** | Электронный блок в сборке. Без него линия встаёт. Карточка: [Продукт_К-12.md](Продукт_К-12.md) |
| **ASM-100 / ASM-200** | Готовые сборочные узлы (стандарт / премиум) |
| **Дебиторка (дни)** | Сколько дней в среднем ждут оплату от клиентов (цель компании ≤ 42) |
| **OTIF** | Доля поставок «вовремя и полностью» |
| **OEE** | Показатель эффективности оборудования (загрузка линии) |
| **Выручка CRM** | Сумма сделок со статусом «выигран» в системе продаж. Может не совпадать с 1С |
| **Управленческая выручка** | Выручка в 1С после возвратов и корректировок |
| **Зелёный статус ERP** | Оценка офиса проектов по плану; не значит «нет сбоев» |
| **Двойной учёт** | Параллельный учёт в Excel и ERP — [двойной_учёт.md](../05-ERP_и_склад/документация/двойной_учёт.md) |
| **СЭД** | Система поручений (статусы «исполнено») |
| **NordSupply / EU-Nord** | Один и тот же основной поставщик К-12 |
