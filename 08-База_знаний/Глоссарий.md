# Глоссарий СеверПром

| Термин | Значение |
|--------|----------|
| **К-12 / K12** | Электронный блок управления в сборке. Критический компонент. Без него линия встаёт. |
| **ASM-100 / ASM-200** | Готовые сборочные узлы (стандарт / premium). |
| **DSO** | Days Sales Outstanding — дни оборота дебиторки. |
| **OTIF** | On Time In Full — доля поставок вовремя и полностью. |
| **OEE** | Overall Equipment Effectiveness. |
| **CRM-выручка** | Сумма сделок со статусом won в CRM. Может не совпадать с 1С. |
| **Управленческая выручка** | Выручка в 1С после возвратов и корректировок. |
| **Зелёный статус ERP** | Оценка PMO по плану проекта; не тождественна отсутствию инцидентов. |
| **Dual-run** | Параллельный учёт в Excel и ERP. |
| **BAN** | Внутренний код клиента в старых файлах коммерции (редко); предпочтительно `customer_id`. |
| **СЭД** | Система электронного документооборота (поручения, статусы исполнено). |
| **V-NORD / EU-Nord** | Один и тот же поставщик NordSupply AB. |
