# ООО «СеверПром» · учебная компания для работы с ИИ

Вымышленная организация. Все данные учебные.

Начните с [СТАРТ_ЗДЕСЬ.md](СТАРТ_ЗДЕСЬ.md). Канонические значения и правила версий —
в [00-О_компании/КАНОН_ДАТАСЕТА.md](00-О_компании/КАНОН_ДАТАСЕТА.md).

Репозиторий для **руководителей**: письма, отчёты, таблицы как из Excel, протоколы, договоры, шаблоны, задания.

**Редактор (WorkAI):** читайте [файлы-по-дням.md](файлы-по-дням.md) — минимальные наборы файлов по дням.  
Рабочая модель курса: **GPT-5.4 Mini** · режим **Ask** · файлы через `@`.  
Rules и Skills на части 2 показывает ведущий с экрана; повторить дома можно по раздатке курса.

Критическая деталь сборки — блок **К-12** (см. [08-База_знаний/Продукт_К-12.md](08-База_знаний/Продукт_К-12.md)).

## Как открыть (без Agent)

1. GitHub → **Code → Download ZIP** (или готовая копия с флешки)  
2. Распаковать  
3. Редактор: **File → Open Folder** / **Открыть папку** → эта папка  
4. Режим **Ask** · модель **GPT-5.4 Mini** · задача из [11-Задачи_для_AI/](11-Задачи_для_AI/) · файлы через `@`  

Для публичного ZIP вход на GitHub **не обязателен**.
