# ООО «СеверПром» · учебная компания для работы с AI

Вымышленная организация. Все данные учебные.

Репозиторий сделан **для руководителей**: письма, отчёты, таблицы как из Excel, протоколы, договоры.  
Разбирать SQL и логи систем **не нужно** — это лежит отдельно для IT (папка `99-…`).

Критическая деталь сборки — блок **К-12**.

---

## Как открыть

1. Скачайте / клонируйте репозиторий  
2. В Cursor: **File → Open Folder** → эта папка  
3. Возьмите задачу из `11-Задачи_для_AI/` или задайте свой вопрос по файлам  

---

## Карта папок (для руководителя)

| Папка | Что внутри |
|-------|------------|
| `00-О_компании` | Кто мы, структура, бонусы продаж |
| `01-Документы` | Политики, поручения, инвестиции, новости |
| `02-Письма` | Переписка отделов |
| `03-Отчеты` | Отчёты; у продаж и финансов есть **версии** v1/v2/v3 |
| `04-Таблицы` | Выгрузки «как Excel» (CSV) |
| `05-ERP_и_склад` | Статусы склада / закупок понятным языком + таблицы |
| `06-Совещания` | Календарь и протоколы |
| `07-Договоры` | Поставщики, Альянс-Сервис |
| `08-База_знаний` | Глоссарий (К-12, дебиторка, …) |
| `09-Расхождения` | Где разные системы говорят разное |
| `10-Кадры` | Люди, оценки, увольнения |
| `11-Задачи_для_AI` | Готовые вопросы для чата |

## Только если вы IT / настраиваете агента

`99-Для_IT_и_агентов/` — SQL, сырые логи, API-заглушки, матрица доступа.  
Руководителю на курсе **можно не открывать**.
