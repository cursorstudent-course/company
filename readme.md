# ООО «СеверПром» · учебная компания для работы с AI

Вымышленная организация. Все данные учебные.

Репозиторий для **руководителей**: письма, отчёты, таблицы как из Excel, протоколы, договоры.  
SQL и сырые логи систем — только в [99-Для_IT_и_агентов/](99-Для_IT_и_агентов/) (**на курсе не открывать**).

**Cursor Free:** читайте [FREE-режим.md](FREE-режим.md) — минимальные наборы файлов по дням.  
В корне: `.cursorignore` (папка `99` не индексируется).  
Rules и Skills на части 2 показывает ведущий с экрана; повторить дома можно
по раздатке курса. Готового rule в репозитории нет — дисциплину `@` держим сами.

Критическая деталь сборки — блок **К-12** (см. [08-База_знаний/Продукт_К-12.md](08-База_знаний/Продукт_К-12.md)).

---

## Как открыть (без Agent)

1. GitHub → **Code → Download ZIP** (или готовая копия с флешки)  
2. Распаковать  
3. Cursor: **File → Open Folder** → эта папка  
4. Режим **Ask** · задача из [11-Задачи_для_AI/](11-Задачи_для_AI/) · файлы через `@`
