# СеверПром — учебный датасет Дня 2

Текущий комплект курса «ИИ для руководителей v2»: от чтения источников к проверенному проекту решения директору. Все события, сотрудники и цены учебные. По указанию организатора этот комплект заменяет прежний датасет компании; старые версии остаются в истории Git.

В составе: упражнения А–Ж и пять резервных карточек; совещание на 4043 слова; два письма DOCX; 900 синтетических расходов за август–октябрь 2026 в XLSX; два PDF-предложения; MD/DOCX-шаблоны записки и требования к автономному HTML-докладу. Основная самостоятельная работа — максимум 90 минут, не четыре часа.

WorkAI, базовая модель DeepSeek V4.1 Flash при её доступности. Прогон в WorkAI/DeepSeek не выполнен: проведены технические проверки файлов, расчётов и форматов. Возможности конкретного окружения проверяет преподаватель заранее.

Источники после получения: Documents/AI-Course/company. Результаты: Documents/AI-Course/results. Участники не меняют исходники, не вводят команды и не устанавливают библиотеки. Для получения компании предусмотрен [готовый промпт агенту](14-День_2_практики/08_Промпты/00_Получить_компанию.txt).

Материалы преподавателя, ответы и контрольные суммы в этот репозиторий не включены. Файлы дополнительных условий выдаются по этапам. Презентации и материалы других дней в этом репозитории отсутствуют; прежние ссылки на удалённые разделы больше не действуют.
