# ООО «СеверПром» · учебная компания

**Это вымышленная организация для тренировки работы с AI.**  
Все цифры, письма и отчёты — учебные. Не используйте как реальные данные.

Небольшое производство: одна сборочная линия, ~120 человек.  
Критическая деталь — электронный блок **К-12** (без него линия встаёт).

---

## Как открыть

1. Скачайте / клонируйте этот репозиторий  
2. В **Cursor**: File → Open Folder → эта папка  
3. Справа откройте чат  
4. Возьмите готовый запрос из `12-Готовые_запросы_для_AI` или напишите свой  

**Не загружайте сюда секреты своей настоящей компании.**

## Главные расхождения (так задумано)

| Показатель | Одна версия | Другая версия |
|------------|-------------|---------------|
| Маржа за июнь | Коммерция: **15%** | Финансы: **12%** |
| Выручка за июнь | Коммерция: **40,5 млн** | Финансы: **39,8 млн** |
| Дебиторка (дней) | Цель: **≤ 42** | Факт: **48** |
| Запас К-12 | По решению: **6 недель** | По факту: **~2 недели** |
| Проект ERP | PMO: **85%, зелёный** | Сбои: **12 критических** / месяц |

Задача — научиться **сверять** источники, а не верить одному отчёту.
